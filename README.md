# ashu_portfolio

A premium, modern dark-themed developer portfolio built with Flutter.

## 🚀 Overview
This portfolio showcases a highly interactive and responsive UI, featuring:
- **Glassmorphism Design**: Using custom backdrop blurs and soft shadows.
- **Advanced Animations**: Powered by `flutter_animate` for smooth entrance and hover effects.
- **Interactive Projects Flow**: Auto-scrolling infinite carousel for project cards.
- **Skill Progress Visualization**: Shimmer-animated gradient progress bars with icons.
- **Responsive Layouts**: Optimized for Desktop, Tablet, and Mobile devices.

## 🛠️ Technology Stack
- **Framework**: Flutter (Web & Mobile)
- **State Management**: GetX
- **Animations**: flutter_animate
- **Styling**: Custom Theme with Glassmorphism components

## 📂 Project Structure
- `lib/features/`: Feature-based modular structure.
- `lib/utils/components/`: Reusable premium UI components.
- `lib/constants/`: App-wide strings, colors, and theme data.
- `lib/controllers/`: Business logic and state management.

## 🏗️ Architecture
The project follows a modular, feature-wise structure to ensure maintainability and scalability. Each section of the home page is extracted into its own widget for better code management.
